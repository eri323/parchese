# Decisiones

Cada decisión que cambia el rumbo del proyecto queda en un archivo numerado. Se crea con `/registrar-decision` a
partir de la [plantilla](_plantilla.md).

Una decisión **aceptada** no se vuelve a discutir. Si cambia, se crea una nueva y la anterior queda marcada como
*reemplazada*.
